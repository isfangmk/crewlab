## 8. 综合建议优先级

**第一梯队（改动小、证据硬、可感知强）**
1. **审批待办闭环**（§7.2）——三段现成代码只差接线，审批是产品唯一人工阻断环节，值得最先做。
2. **"已打断"标记 + 会话重命名**（§7.2）——契约都已签好，纯前端补齐。
3. **SSE 断连重连续传**（§7.3）——复用 `notifications.ts` 已验证实现，直接消除"卡住要刷新"的高频痛点。

**第二梯队（用户价值高、需新增能力）**
4. ~~**助理回答一键复用**（§7.1）——聊出的结论能直接沉淀，价值最高。~~ **已否决并移除（2026-11-18）**：转技能/转任务为空壳跳转，存知识有污染知识库风险，用户实测无必要。
5. **消息全文检索 + 定位跳转**（§7.1）——"记得某句话却找不到"是真实痛点。
6. **@ 提及扩展**（§7.1）——对话框里直接引用/触发技能、工作流。

**第三梯队（工程韧性 / 中等工作量）**
7. MCP 连接熔断降级、embedding 缓存与超时（§7.3）；长会话上下文压缩、产出物二次消费（§7.1）。
