# AI 工作台 — 后续产品功能迭代计划

> 文档版本：v1.0 · 2026-11-09  
> 基线：`docs/AI工作台-功能迭代.md`（P0 已基本落地）  
> 定位不变：以**对话为中心**的 Agent 工作台（Tool / Skill / MCP / 知识库 / 模型 / 审批）；运行时坚持 **Google ADK**，不做 AIOps、不做可视化工作流编排替代品。

---

## 0. 业界能力地图（调研摘要）

对照开源/自托管产品常见能力（主要来源：Open WebUI、Dify、LibreChat、Langfuse、mcp-workbench、Agent Studio、Copilot Studio / GitHub Copilot Harness 等公开文档与仓库说明），AI 工作台类产品通常覆盖以下能力族：

| 能力族 | 业界常见能力 | 代表产品倾向 |
| --- | --- | --- |
| **对话与模型** | 多厂商模型、流式输出、会话分叉/搜索、多模型对比、预设/Preset、附件与多模态 | LibreChat / Open WebUI |
| **智能体** | 人设与指令、工具白名单、知识绑定、子 Agent / 多 Agent 协作、Memory | Copilot Studio / Agenta / LibreChat Agents |
| **工具与扩展** | 内置 Tool、MCP、OpenAPI/插件、按需加载、人工审批策略 | mcp-workbench / Open WebUI / Agent Studio |
| **技能** | `SKILL.md` 渐进披露、市场/导入、斜杠命令、插件包 | mcp-workbench / Claude Code 生态 |
| **知识 / RAG** | 多格式入库、切块、向量 + 关键词混合检索、重排、引用溯源、检索 Playground | Dify / Open WebUI / mcp-workbench |
| **安全与治理** | 审批闸门、RBAC/SSO、审计日志、密钥托管、配额 | LibreChat / 企业向工作台 |
| **可观测与评测** | Trace、Token/成本、Prompt 版本、数据集与 Eval、Playground | Langfuse / Dify |
| **自动化与发布** | 定时任务、Webhook 触发、对外 API / Embed、IM 渠道 | Agenta / Dify / n8n |
| **执行沙箱** | 代码解释器、终端、浏览器、文件工作区 | Open WebUI / OpenHands / Agenta |
| **创作与体验** | Artifacts、语音、图像生成、笔记/频道 | LibreChat / Open WebUI |

**对本项目的取舍原则：**

1. **先做「对话 × Agent × Tool/Skill/MCP × 知识 × 审批」闭环的深度**，再扩展自动化与渠道。  
2. **不做**可视化 Chatflow/Workflow 画布（Dify/n8n 赛道）、不做设备/监控等 AIOps。  
3. 可观测、多用户、沙箱、发布渠道进入后续里程碑，且优先可插拔（对接 Langfuse 等）而非自研全家桶。

## 2. 一、已有功能的迭代

按模块列出「痛点 → 目标 → 建议优先级」。优先级：`P1` 近期、`P2` 中期、`P3` 远期。

### 2.1 对话体验

| ID | 迭代项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| C1 | 会话管理增强 | 搜索历史会话、置顶、归档、按助理/模型筛选；长会话摘要折叠 | P1 |
| C2 | 消息操作 ✅ | 复制、重新生成、编辑用户消息后重跑、分支对话（fork） | P1 |
| C3 | 引用与溯源展示 | 知识命中/网页搜索结果在气泡内统一「来源」区（标题/链接/摘录） | P1 |
| C4 | 多模态完善 | 附件类型扩展（PDF/文本）、粘贴多图、附件生命周期与清理策略 | P2 |
| C5 | 思考与工具时间线 | 思考/工具/审批/正文统一时间线；失败工具可展开原始错误 | P2 |
| C6 | 多模型对照 | 同一提示并排跑 2 个模型（业界 LibreChat 常见）；可选 | P3 |

### 2.2 助理（Agents）

| ID | 迭代项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| A1 | 能力绑定可视化 | 白名单工具/技能/MCP 用分组勾选 + 预览「实际可见工具数」 | P1 |
| A2 | 人设与示例 | 系统提示模板库、少样本示例、输出格式约束（JSON/清单） | P1 |
| A3 | 知识库范围 | 助理可绑定知识路径/文档集，检索默认带 scope | P2 |
| A4 | 子 Agent / 委托 | ADK `sub_agents`：主助理把专项任务交给子助理（保持 ADK，不自研编排） | P2 |
| A5 | 版本与回滚 | 助理配置版本号；对话可锁定某版本 | P3 |

### 2.3 工具（Builtin Tools）

| ID | 迭代项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| T1 | 运行体验对齐 MCP | 结果复制、错误分类提示、参数校验与类型控件（bool/enum） | P1 |
| T2 | 工具目录元数据 | 参数说明、示例、风险说明写入目录 API；前端详情更完整 | P1 |
| T3 | 扩展内置工具集 | 在 ADK `FunctionTool` 下增加只读实用工具（如时间/计算器/JSON 校验），仍走统一注册表 | P2 |
| T4 | 运行审计 | 手动运行写入审计表（谁、何时、参数摘要、结果摘要） | P2 |

### 2.4 技能（Skills）

| ID | 迭代项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| S1 | 目录可读性 | 按 category 稳定分组；展示声明的 `adk_additional_tools`、风险、是否可装配 | P1 |
| S2 | 热加载 / 校验 | 刷新时装载；frontmatter 非法时页面明确报错（禁止静默跳过） | P1 |
| S3 | 导入与导出 | ZIP/`SKILL.md` 包导入；导出当前技能包（仍不做 Marketplace 商店） | P2 |
| S4 | 斜杠命令映射 | 对话输入 `/技能名` 快捷激活（业界 skills + slash 常见） | P2 |

### 2.5 MCP

| ID | 迭代项 | 说明 | 优先级 |
| --- | --- | --- | --- |
| M1 | 传输与鉴权 | OAuth/PKCE、加密 Header、stdio 桥（按需）；连接健康心跳 | P1 |
| M2 | 审批策略细化 | per-server：never / 非只读询问 / always（对齐 mcp-workbench） | P1 |

### 2.6 知识库

| ID | 迭代项 | 说明 | 优先级 |
| --- | --- | --- | --- |

## 3. 二、未开发功能的迭代

以下为当前产品**基本没有或仅占位**、但业界工作台普遍具备或强需求的能力。仍遵守：不自研 Agent 运行时；不做 AIOps；不做 Dify 式画布作为主路径。

### 3.1 P1 — 补齐「能用、可控、可查」

| ID | 功能 | 价值 | 备注 |
| --- | --- | --- | --- |
| N1 | **多用户与 RBAC** ✅ | 团队共用工作台；角色：管理员 / 开发者 / 只读 | 本地多用户已落地；SSO 见 N2 |
| N2 | **SSO / OIDC** | 对接企业 IdP | 可与 N1 同里程碑 |
| N3 | **运行可观测（对接优先）** | Trace、延迟、错误、token；优先接 Langfuse/OTel | 避免自研完整观测台 |
| N4 | **Prompt / 助理 Playground** | 改人设与参数后侧栏试跑，不污染正式会话 | |
| N5 | **会话导出与分享** | Markdown/JSON 导出；只读分享链接（可选） | |
| N6 | **知识混合检索落地** | 见 K3；属「未做完的知识能力」 | 与已有知识库迭代重叠，单独立项便于排期 |

### 3.2 P2 — 自动化与协作

| ID | 功能 | 价值 | 备注 |
| --- | --- | --- | --- |
| N7 | **定时 / 触发助理** | Cron 跑巡检类任务；Webhook 触发一轮对话 | Agenta/Open WebUI Automations 同类 |
| N8 | **对外 Chat / API** | 将某助理发布为 API 或嵌入小部件（域名白名单） | Dify BaaS / Embed 同类 |
| N9 | **评测与回归集** | 黄金问答集、工具调用断言、版本对比 | Langfuse Datasets / Evals |
| N10 | **Memory（跨会话记忆）** | 用户级/助理级长期记忆；需显式开关与可清除 | Copilot Harness Memory |
| N11 | **技能/MCP 插件包** | 从 Git 仓库安装一组 skills+mcp（审核后启用） | 非开放商店，偏私有源 |

### 3.3 P3 — 体验扩展（按需）

| ID | 功能 | 价值 | 明确边界 |
| --- | --- | --- | --- |
| N12 | **代码解释器 / 沙箱** | 对话内跑 Python 出表/图 | 独立沙箱服务；不进宿主机任意 Shell |
| N13 | **Artifacts** | 代码/HTML/Mermaid 侧栏渲染 | LibreChat 同类 |
| N14 | **语音输入输出** | 会议纪要、免提问答 | |
| N15 | **图像生成** | 文生图工具 | 可选插件，非核心 |
| N16 | **IM 渠道** | Slack/飞书/企微 Bot | 渠道适配层，对话内核复用 |
| N17 | **多 Agent 理事会** | 多模型合议同一问题 | Agent Studio Model Council；谨慎引入复杂度 |

### 3.4 明确不纳入本产品主线（保持非目标）

- 可视化工作流画布、Zapier/n8n 式集成中台  
- 设备 / Edge / K8s / 监控告警 / WebSSH 等 AIOps  
- 自研 Agent Loop、自研审批执行器、绕过 ADK confirmation  
- 开放式公共 Skill 商店（可做「私有 Git 源」，不做运营型市场）

## 4. 建议路线图（季度视角）

```text
近程（1～2 个迭代）
  已有：C1–C3、A1–A2、T1–T2、S1–S2、M2/M5、K1–K4、G1–G2、E1–E3
  新建：N1（可先做本地多用户）、N3、N5、N6

中程
  已有：C4–C5、A3–A4、M1/M3/M4、K5、L1–L2、S3–S4、T3–T4
  新建：N2、N4、N7、N9、N10

远程
  新建：N8、N11–N16（按业务信号裁剪）；C6 / N17 仅在有明确需求时启动
```

验收习惯延续现有规范：**真实模型 / 真实 MCP / 真实嵌入 / 真实 PG**；契约不符显式失败；用户可见文案不泄漏内部实现名。

### 4.1 本迭代落地记录（2026-11-09）

| ID | 落地内容 | 关键实现 |
| --- | --- | --- |
| N1 | 用户与权限页 `/users` | 本地账号创建、角色选择（admin/developer/viewer）、启停用、改角色、重置密码（吊销旧 Token）、删除账号；bootstrap 管理员与当前登录账号有保护；前后端角色枚举统一 |
| G2 | 审计日志 `/audit` + 后端留痕 | `GET /api/v1/audit` 支持动作/资源/操作者/时间筛选、`sort_by=created_at` + `sort_dir` 排序与分页；审批、工具、MCP、凭证、用户动作统一写审计 |
| C2 | 消息操作 | 气泡悬浮工具条：复制、编辑用户消息重发、重新生成、分支对话；重发与分叉同步重建 ADK 事件流，避免模型看到已截断的历史 |

配套测试：`backend/tests/test_audit_api.py`、`backend/tests/test_adk_replay.py`、`backend/tests/test_auth_users.py`、`web/src/pages/Users.test.tsx`、`web/src/pages/Audit.test.tsx`、`web/src/components/MessageBubble.test.tsx`。
