# 部署与运维指南

适用版本：当前主干（FastAPI + React/Vite 单机部署）。

## 服务构成

| 服务 | 技术栈 | 默认地址 | 说明 |
|---|---|---|---|
| 后端 API | FastAPI + Uvicorn | http://127.0.0.1:18080 | REST + SSE，日志写 `logs/backend.log` |
| 前端 | Vite 开发服务器 | http://127.0.0.1:5173 | 生产构建另行打包 |
| 沙盒 | 本地进程或 Docker | - | 由 `SANDBOX_EXECUTOR` 决定（local / docker） |

## 启停脚本（仓库 `scripts/` 目录）

- `service.ps1 start|stop|restart [backend|frontend|all]`：前后端统一启停，默认 `all`；PID 记录在 `logs/<name>.pid`，重启会先停旧进程再起新进程并输出 PID 与日志路径。
- `backend-typecheck.ps1`：类型检查。
- `eval-gate.ps1`：评测门禁。

**纪律：后端禁用 `--reload`。改动后端代码后必须执行 `scripts/service.ps1 restart backend` 使生效，并访问 `/healthz` 确认 `{"status":"ok"}`。**

## 数据存储

- `data/ai_workbench.db`：SQLite 业务库（会话、消息、产出物、审批、审计、配置等全部表）。
- `data/vectors.db`：独立向量库，单表 `vector_items`，按 `namespace` 区分语料（knowledge_chunks / memory_items / mcp_tools）。
- 知识库上传原件落盘保存，可在文档详情页下载。
- 备份：停服后整体拷贝 `data/` 目录即可；两库分开便于单独迁移。

## 关键环境变量（`backend/.env`）

| 变量 | 用途 |
|---|---|
| `DATABASE_URL` | 业务库连接串（sqlite+aiosqlite） |
| `VECTOR_BACKEND` | 向量后端（sqlite / pgvector） |
| `EMBEDDING_BASE_URL` / `EMBEDDING_MODEL` / `EMBEDDING_API_KEY` / `EMBEDDING_DIM` | 文本嵌入服务 |
| `SEED_LLM_PROVIDER` / `SEED_LLM_MODEL` / `SEED_LLM_API_KEY` 等 | 首个 LLM 供应商种子配置 |
| `AUTH_ADMIN_EMAIL` / `AUTH_TOKEN` | 初始管理员账号（保密） |
| `SANDBOX_EXECUTOR` / `SANDBOX_IMAGE` / `SANDBOX_TIMEOUT_SECONDS` / `SANDBOX_NETWORK_ENABLED` | 沙盒执行器与安全边界 |
| `CREDENTIAL_ENCRYPTION_KEY` | 凭据加密密钥（保密） |

## 健康检查

`GET /healthz` 返回 `{"status":"ok"}` 即服务正常；观测页（/observability）提供运行期指标与工具调用观测。
