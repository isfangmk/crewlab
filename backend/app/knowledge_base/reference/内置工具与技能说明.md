# 内置工具与技能说明

## 内置工具（对话内可调用）

| 工具 | 用途 |
|---|---|
| run_python | 沙盒执行 Python，产出图表/表格/文件产出物 |
| remember_memory / recall_memory | 跨会话记忆的保存与回忆 |
| query_knowledge | 语义检索组织知识库（命中带文档定位） |
| web_search | 联网网页搜索（对话开启联网时可用） |
| ask_user | 向用户澄清：给出选项或表单，用户作答后自动继续 |
| list/get/run_workflow 等 | 工作流查询与运行 |
| get_workflow_run / list_workflow_runs | 运行记录查询 |

## 图表：唯一通道是 run_python 的 chart() 助手

`chart(data, chart_type="line", title="图表")` 把数据直接变成图表产出物：

- **不要手写 ECharts 配置，正文里的 ECharts JSON 不会被渲染成图。**
- data 数据契约（按图型取字段）：折线/面积 `{"x", "series": [{"name", "data"}]}`；柱/条/堆叠/分组/漏斗/箱线/瀑布 `{"categories" 或 "x", "series"}`（瀑布首项为起点、其后为增量）；饼/环形 `{"categories", "series"}`；散点 `{"points": [{"x", "y"}]}`；雷达 `{"indicators": [{"name", "max"}], "series"}`；仪表盘 `{"value", "name"}`；热力图 `{"x", "y", "values": 二维数组}`；矩形树图 `{"data": [{"name", "value", "children"}]}`。
- chart_type 支持：line / area / bar / hbar / stacked_bar / grouped_bar / pie / donut / scatter / radar / gauge / funnel / heatmap / treemap / boxplot / waterfall。
- 配色与文字样式由前端主题统一注入，数据里不用给颜色；带单位的数值（如 "80%"）会被拒绝，让它改数据重试。
- 高级用法：emit_chart(option, title) 可直接提交现成 ECharts option；emit_table/emit_file 产出表格与文件。
- 产出物走暂存区落库（artifacts 表），不进模型上下文——图表 JSON 不占输出 token。

## 澄清交互（ask_user）

ask_user 提供结构化澄清能力：向用户提问并在卡片中收集回答，作答后本轮自动继续。用法：

- `question` 说明要问什么；需要候选选择时给 `options`；需要填写时给 `fields`（key/label/placeholder/required）。
- 用户在卡片作答后本轮自动继续；不要把占位符塞进其他工具的 arguments 先调用。
- 被委派的子任务里不向用户提问，按最合理假设继续并注明假设。

何时用纯文本提问、何时用此工具，由模型按当前提问自行判断，本文只描述能力契约。

## 技能（Skills）

- 技能是带 SKILL.md 的目录，按描述匹配后由模型 load_skill 使用；内置技能含 knowledge-search。
- 图表绘制不再走技能（chart-builder 已移除），统一走 run_python chart()。

## 审批暂停/恢复

高危工具或 ask_user 会触发暂停：前端出卡片，用户批准/驳回/作答后经审批流恢复执行，全程留审计。
